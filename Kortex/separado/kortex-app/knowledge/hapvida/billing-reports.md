# Hapvida Billing Reports

Source: Telegram Koa chat, visible messages from 2026-09-09 and 2026-09-10.
Confidence: high for training content, but this is not a beneficiary movement workflow.

## Entry Path

1. Open `Kit faturamento`.
2. Select `6 - Hapvida Relatório - Kit`.
3. Access `Hapvida Relatório - Kit`.
4. In `CPF/CNPJ`, select the company access key.
5. Inform password through a secure broker/executor only.
6. Click `PROSSEGUIR`.

## Primary Path

1. Open `BAIXAR ARQUIVOS - DOWNLOAD (Novo)`.
2. Review the file list.
3. Identify the requested report by file description, report type and competence.
4. Download the monthly report for the requested competence.
5. Check whether coparticipation was also obtained.

## Fallback Path For Coparticipation

1. Return to main menu.
2. Open `BAIXAR ARQUIVOS - DOWNLOAD (Anterior)`.
3. Find file candidates ending in `_PSICO.PDF`.
4. Validate the competence before downloading.
5. If download does not start automatically, click `clique aqui` once.

## Validation Rules

- Do not choose a file only because it is a PDF.
- Do not choose the first `_PSICO.PDF` automatically.
- Validate description and competence.
- A complete kit expects monthly report and coparticipation report.
- If only one is available, download and validate the available one and report the missing one separately.
- Success requires downloaded, saved, opened and validated files.

## File Naming

- `RELATÓRIO MENSALIDADE - <EMPRESA> - <CÓDIGO> - <MM-AAAA>.pdf`
- Coparticipation naming was still pending final confirmation in visible Telegram messages:
