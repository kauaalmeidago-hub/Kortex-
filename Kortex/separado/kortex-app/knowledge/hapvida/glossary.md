# Hapvida Glossary

- `Kit faturamento`: Area used for billing-kit files and reports.
- `6 - Hapvida Relatório - Kit`: Shortcut/path cited for Hapvida report downloads.
- `CPF/CNPJ`: Login/access field where the company key is selected.
- `chave de acesso`: Company access key; Telegram training says it starts with the company's CNPJ.
- `BAIXAR ARQUIVOS - DOWNLOAD (Novo)`: Primary report download path.
- `BAIXAR ARQUIVOS - DOWNLOAD (Anterior)`: Fallback report download path, especially for coparticipation.
- `_PSICO.PDF`: File suffix used to identify coparticipation report candidates.
- `competência`: Month/year reference for report files, represented as `MM-AAAA`.
- `credentialRef`: Safe backend reference to portal credentials. It must not contain the password itself.
- `artifact`: File produced by automation, such as card PDF, confirmation PDF or screenshot.
